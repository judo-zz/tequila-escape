# テキーラから逃げろ！

コンカフェで始まった突然の乾杯タイムを、飲みすぎず・疑われすぎず・空気を守りながら 10 ターン生き残るコマンド選択型ブラウザゲーム。

## 起動方法

```bash
# ローカルサーバー（推奨）
python3 -m http.server 8000
# → http://localhost:8000/index.html

# または直接開く（Clipboard API は http/https 環境推奨）
open index.html
```

## ファイル構成

```
tequila-escape/
├── index.html          # ゲーム本体（HTML / CSS / JS 完結）
└── assets/
    ├── milk.png        # キャラ立ち絵（透過 PNG）
    └── bg.png          # 背景画像
```

画像が存在しない場合は絵文字（🥃）にフォールバックします。

## ゲームの流れ

1. タイトル「乾杯する」でゲーム開始
2. 各ターンで 4 つのコマンドから 1 つ選択
3. 10 ターン生き残れば勝利（またはキャストの酔い 100 で即勝利）
4. 結果画面でスコア・称号・コピーボタン

## ゲージ仕様（初期値）

| ゲージ | 初期値 | 敗北/勝利条件 |
|---|---|---|
| 自分の酔い | 0 | 100 以上で敗北 |
| 疑惑 | 20 | 100 以上で敗北 |
| 空気（テンション） | 60 | 0 以下で敗北 |
| キャストの酔い | 0 | 100 以上で勝利 |

## コマンド仕様

### 通常コマンド

| コマンド | 効果 | 備考 |
|---|---|---|
| 🥃 飲む | 自酔+22 / 卡酔+8 / 疑-12 / 空気+8 | 最も安定 |
| 🎭 飲んだフリ | 成功率 = clamp(70 - 疑×0.45 + 空気×0.2, 20, 90)% | 成功: 卡酔+15 / 疑+18 / 空気+8、失敗: 自酔+5 / 疑+35 / 空気-20 |
| 💬 話を逸らす | 成功率 = clamp(55 + 空気×0.35 - 疑×0.25 - 連続補正, 25, 90)% | 成功: 疑-22 / 空気+8、失敗: 疑+15 / 空気-15。連続2回目-15%、3回目以降-30% |

### その他コマンド

| コマンド | 効果 | 備考 |
|---|---|---|
| 💧 水を飲む | 自酔-20 / 疑+18 / 空気-5 | 連打で疑惑100敗北 |
| 📸 チェキに逃げる | 疑-8 / 空気+12 / スコア-100 / チェキ残-1 | 1ゲーム3回まで |
| 🚻 トイレ | 自酔-30 / 疑+25 / 空気-12（連続時 +20） | トイレ残数 3 回以上で称号変化 |

### ターン終了時スコア加算

```
スコア += 空気 × 5 + キャスト酔い × 3 + (100 - 疑惑) × 2
```

## 称号一覧

### 敗北（先に発生した条件で確定）

| 条件 | 称号 |
|---|---|
| 自分の酔い 100 | 無事終電消失 |
| 疑惑 100 | グラス見られおじさん |
| 空気 0 | 空気破壊おじさん |

### 勝利（優先順で最初にヒットしたものを採用）

| 条件 | 称号 |
|---|---|
| キャスト酔い 100 | 乾杯の支配者 |
| チェキ 3 回使用 | チェキ避難民 |
| トイレ 3 回以上 | 膀胱の戦士 |
| 自酔 ≥ 90 | 限界飲酒回避おじさん |
| 疑惑 ≥ 90 | バレ寸前の魔術師 |
| 空気 ≥ 90 | フロアの盛り上げ隊長 |
| 自酔 < 30 | 素面の策士 |
| 疑惑 < 30 | 自然体の逃亡者 |
| それ以外 | 夜の生還者 |

## 演出

| 状態 | 演出 |
|---|---|
| 自酔 ≥ 80 | 画面揺れ・stage ぼかし・酔いゲージグロー |
| 疑惑 ≥ 80 | 背景暗転・👁👁 出現・疑惑ゲージグロー |
| 空気 ≥ 80 | ネオン強化・キラキラ粒子・立ち絵グロー |
| 空気 ≤ 25 | 彩度低下・暗転・吹き出し冷色 |
| 飲んだフリ失敗 | カットイン「今、飲んでなかったよね？」800ms |

- [x] カットインは 800ms で自動消去（prefers-reduced-motion 対応）

- [x] コピー後にボタン文言が「コピーしました！」に 2 秒変化
- [x] Clipboard API 失敗時は「コピーできませんでした」をボタンに表示

- [x] `100svh` で Safari のアドレスバー伸縮に対応

## 既知の制約

- 外部ライブラリなし（HTML / CSS / JavaScript のみ）
- ローカルストレージ未使用（セッションをまたいだスコア保存なし）
- assets/ フォルダが空の場合は絵文字フォールバックで動作
- Clipboard API は `https://` または `localhost` 環境が必要（http 環境では execCommand フォールバック使用）

## キャラ画像の差し替え方法

1. `assets/milk.png` を透過 PNG で上書き
2. `assets/bg.png` を好きな背景画像で上書き
3. ブラウザをリロード

コード変更は不要です。
